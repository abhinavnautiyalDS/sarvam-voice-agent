# Qwen LoRA language classifier

The Qwen LoRA files `adapter_config.json` and `adapter_model.safetensors` are downloaded from the public `hinglish-language-switch-llm` repository on first use and cached here. The base model `Qwen/Qwen2.5-0.5B-Instruct` is downloaded from Hugging Face by Transformers. Set `HINGLISH_LLM_ADAPTER_PATH` or `HINGLISH_LLM_ADAPTER_RAW_BASE` to override the defaults.
